## 🚀 Featured Projects

### 1. [NeuralOS — Reinforcement Learning CPU Scheduler](https://github.com/AayushUpadhyay1210/NeuralOS)

- Modelled CPU scheduling as a Markov Decision Process (MDP).
- Trained an action-masked PPO agent using PyTorch and Stable-Baselines3.
- Achieved approximately **25% lower mean cost** than the best baseline on 70 held-out traces.
- Built a FastAPI backend and React dashboard.
- Validated with 186 tests.

### 2. [DPI Engine — Deep Packet Inspection System](https://github.com/AayushUpadhyay1210/DPI-Engine)

- Developed a multithreaded Deep Packet Inspection engine using C++17.
- Classifies network traffic using TLS SNI, HTTP Host, and DNS information.
- Implements bidirectional flow tracking and IP/CIDR, domain, and application-based blocking.
- Uses hash-partitioned workers and bounded queues for concurrent packet processing.
- Validated with tests, fuzzing, and sanitizers.

### 3. [MineGuard — Mining Safety Monitoring](https://github.com/AayushUpadhyay1210/MineGuard)

- Developed a mining safety monitoring prototype using simulated sensor data.
- Built an interactive dashboard with hazard indicators and real-time-style alerts.
- Focused on identifying potential rockfall hazards.

### 4. [CampusCart — Student Marketplace](https://github.com/AayushUpadhyay1210/CampusCart)

- Built a responsive marketplace for buying and selling products within a university campus.
- Implemented product listings, shopping cart functionality, and profile pages.
- Developed using HTML, CSS, and JavaScript.
